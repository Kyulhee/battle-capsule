# 현재 트래커

> 최종 업데이트: 2026-09-16. 작업 재개·우선순위 선택에 사용한다. 상세 결과는 [DEVLOG](DEVLOG.md), 제품 범위·일정·후속 트랙은 [MASTERPLAN](MASTERPLAN.md)을 참조한다.

## 현재 목표와 중단점

- M0 운영 정리: 공통 지침, 조건별 문서 읽기/갱신, 선택형 검증, 실험 코드 보관 위치를 적용했다. 게임 코드·승격 기준·공개판은 변경하지 않았다.
- M1은 첫 플레이 가능한 Night BR 종료 판정 중이다. 개발/수동/후보 표면은 `data/mapSpec_night_forest_expanded_candidate.json`의 `night_br_m1_60`으로 유지한다.
- E-088 완료: 엄폐 미도달/null-target 압력 분기의 조기 종료를 실제 handler에서 재현하고 기본 OFF 후보로 수정했다. 안전 경계와 새 동일 소스 대조/후보 pilot은 통과했지만 120/260초 생존과 T10 방향이 악화돼 5-run 확대·기본 적용은 보류한다. 조기 종료 규칙의 정합성과 M1 생존 개선을 구분하며 E078/E081/E088은 혼합하지 않는다. [E-088 결과](DEVLOG.md#e-088-엄폐-미완료-압력-종료-후보-판정)
- E-089 완료: 기존 E067 PCK를 독립 APPDATA에서 실행해 제어된 승리→실제 RESTART 버튼→패배→별도 프로세스 재실행을 검증했다. 정상 기록 2개·성공 배지·설정과 재시작 초기화, 재실행 전후 저장 파일 불변을 확인했다. 게임 코드/패키지는 변경하지 않았으며 자연 경기·EXE 조작·수동 3판 PASS가 아니다. [E-089 결과](DEVLOG.md#e-089-e067-격리-정상-결과재시작재실행-저장)
- E-090 완료: E067 반복 검증에서 서로 다른 경기의 동일 결과가 하나로 합쳐지는 저장 결함을 발견했다. 소스에서 기록 개수를 보존하고 rollback 미러는 같은 항목의 최대 출현 횟수로 병합하도록 수정했다. 수정 소스의 일반 61명 경기 재시작 5회·결과6개·이전 씬 해제·재실행 보존은 PASS다. **기존 E067의 5회 검증은 FAIL로 유지**하며, 단발 PASS를 소급 취소하거나 패키지 수정 완료로 해석하지 않는다. [E-090 결과](DEVLOG.md#e-090-반복-재시작에서-발견한-동일-결과-기록-손실-수정)
- 다음 E-091 우선순위는 저장 수정이 포함된 clean 검증용 artifact 제작과 동일 5회 흐름의 패키지 검증이다. 제작 시 E067을 덮어쓰지 않고 새 빌드 식별자·소스 SHA를 남겨 수동 자료와 연결한다. 이번 E090에는 새 EXE/공개 tag·Release·후속 푸시를 포함하지 않았다. M1 생존 미달·자연 완주·수동3판·장시간 soak는 계속 남는다.
- 시계 후보는 기본 OFF이며 수동 성능/체감·기본값·새 EXE 승격은 보류한다. 2초 하한은 5-run 평균이며 시간 보정·인위적 수집 지연·하한 완화는 하지 않는다. E078/E081 과거 단발 gate FAIL도 소급 변경하지 않는다.

## 수동 검증과 릴리즈

- E-067 패키지 수동 검증 대기: clean 소스 `78b5180`, Windows `builds/playtest/E-067_78b5180/BattleCapsule_E067_78b5180.exe`, 메뉴 `v2.1.0-demo-dev | E-067`. macOS ZIP·checksum도 같은 폴더이며 실제 Mac은 미검증이다.
- E067에는 E090 저장 수정이 없다. 같은 날짜·점수·시간 등 전체 내용이 같은 경기 기록이 합쳐질 수 있어, 반복 저장 검증/배포 후보 통과본으로 취급하지 않는다. 이미 소실된 기록을 원본/backup에서 자동 복구하는 작업은 하지 않았다.
- 수동 확인: 낡은/표준 무기 구분, 재장전/탄약 없음 경고, 총·호환 탄약 확보와 생존·존 압력. E-064 자동 분포와 수동 체감의 괴리는 아직 해소되지 않았다.
- 현재 보호된 수동 JSON은 빌드 식별자가 없어 E067 실행으로 확인되지 않았다. 이를 E067 수동 통과나 자동 60봇 비교군으로 사용하지 않는다.
- 첫 공개 범위: Windows x64, 오프라인 싱글플레이, 한국어, 키보드/마우스, 한 맵 무료 데모. 온라인·99명 기본값·macOS 정식 지원·신규 콘텐츠 확장은 보류한다.
- `v2.1.0-demo-dev`는 제한된 테스트 프리릴리즈다. 공개 stable `v2.0.0-pre-expansion`은 수동/패키지·M2/M3 gate 전 교체하지 않는다.
- 패키징·저장·브랜딩 기반 작업은 병행 가능하다. E089 패키지의 단발 흐름과 E090 수정 소스의 5회 재시작은 구분한다. 수정 패키지·자연 전체 매치·장시간 반복, Forward+ 성능, clean artifact 재현성과 실제 Mac 실행은 미검증으로 남는다. [릴리즈 절차](reference/RELEASE.md)

## 우선순위와 주요 위험

1. E-091에서 저장 수정의 clean artifact와 패키지 반복 검증을 이어간다. 생존 후보의 추가 튜닝·5-run 재추첨 없이 E088 판정은 보존한다.
2. E-067 수동 피드백을 반영해 M1 체감 판정으로 돌아간다. 단발 sanity를 5-run 또는 수동 승격으로 해석하지 않는다.
3. 이후 대표 건물/교전·야간/HUD 슬라이스, 첫 사용자 완주, Windows 공개 RC는 MASTERPLAN의 M2/M3 순서를 따른다.

현재 위험은 M1 생존·교전 압력, 화면 가독성, 수동 저장/패키지 검증 공백이다. 99봇은 구조 안전망이며 체감 목표가 아니다. 수치만 맞추는 전역 드랍 상향이나 신규 기능 확장으로 위험을 우회하지 않는다.
