# v2.1.0-demo-dev 릴리즈 노트

> 2026-09-01. 이 빌드는 Night BR 개발 상태를 확인하기 위한 프리릴리즈이며 안정판이나 공개 데모 RC가 아니다.

## 포함 내용

- `night_br_m1_60` 한 맵에서 플레이어 1명과 봇 60명이 진행하는 10-15분 목표 매치
- POI 밀도에 따른 무기·보급품 배치, 필드 드랍 정리, 자기장과 엄폐를 고려하는 봇 이동
- 야간 가독성, 수관 투명화, 축소된 미니맵, 아티팩트 선택과 기록·설정 저장 골격
- Windows x64와 macOS Universal 2(Intel/Apple Silicon) 빌드
- 제품명 `Battle Capsule`, 표시 버전 `v2.1.0-demo-dev`

## 알려진 제한

- 첫 자기장 전 인원 감소, 실제 파밍 동선, 엄폐 후 재교전 체감은 자동 수치가 개선됐지만 수동 3판 판정이 남아 있다.
- 동일 조건 packaged 측정 한 번에서 AI frame max가 50ms 기준을 넘었다. 일반 플레이 성능과 다중 하드웨어 검증은 완료되지 않았다.
- Windows 실행 파일은 서명하지 않아 SmartScreen 경고가 나타날 수 있다.
- macOS 빌드는 Windows에서 만든 Universal 2 교차 export다. 서명·공증하지 않았고 실제 Mac에서 실행하지 않았으므로 Gatekeeper 경고 또는 실행 차단이 있을 수 있다.
- cold clean export 간 PCK의 byte 단위 재현성은 해결되지 않았다. 각 배포본은 package 내용 계약과 SHA-256 manifest로 식별한다.
- 저장 위치는 과거 프로젝트 식별자를 유지해 Godot 사용자 데이터의 `BattleRoyalePrototype` 경로를 사용한다. 기존 저장 호환성을 위한 임시 결정이다.
- 게임 플레이 데이터는 외부로 전송하지 않는다. 버그 신고에는 OS, CPU/GPU, 빌드 버전과 재현 절차를 함께 적는 것이 좋다.

## 다음 승격 조건

Windows 프리릴리즈는 수동 3판과 재시작·저장 확인을 위한 테스트 산출물이다. 실제 Mac 두 아키텍처 실행, 대표 전투 비주얼/오디오, 첫 사용자 UX, 다중 Windows 환경과 외부 테스트를 통과하기 전에는 안정판 또는 공개 데모 RC로 승격하지 않는다.
